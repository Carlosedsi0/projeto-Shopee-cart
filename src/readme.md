## Objetivo

Criar um carrinho de compras baseados no carinho de compras da shopee, aonde o carrinho armazene intens e faça cálculo de sub-itens automaticamente 

//dominio da aplicação:carrinho de compras

//as entidades reprensentadas
//->carrinho
//->itens
Vamos adcionar mais coisas
Nível 1 — Fácil
Começar aqui

- [ ] Impedir adicionar produtos com quantidade inválida.
- [ ] Verificar se o carrinho está vazio.
- [ ] Mostrar uma mensagem quando um produto for adicionado.
  
  
  Nível 2 — Intermediário
- [ ] Criar uma função para limpar o carrinho.
- [ ] Procurar um produto pelo nome.
- [ ] Alterar a quantidade de um produto.
  
  
  Nível 3 — Mais desafiador
- [ ] Aplicar cupons de desconto.
- [ ] Calcular frete.
- [ ] Criar um resumo completo da compra.
  
  
  Nível 4 — Avançando
- [ ] Salvar os dados do carrinho em um arquivo.
- [ ] Recuperar o carrinho quando iniciar o programa novamente.
